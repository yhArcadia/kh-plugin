# 常用功能

- `开合 @某人` / `kh @某人` / `你谁 @某人` / `他是谁 @某人`：查询对应群友在本群留下的历史头像昵称群名片头衔记录。
- `KH @某人` ：同上，但会同时展示本群所在**互通组**中，被查群友在每个与查询者共同的群中的历史身份记录。

# 排行榜

- `#换头大王` / `#专一大王`：分别按**换头像次数**正序、倒序排行（仅计算头像次数）。
- `#马甲大王`：按**身份变更次数**排行（计算头像、昵称、群名片、头衔、权限变更次数）。
- `#潜水大王` / `#活跃大王`&`#冒泡大王`：按**最久未发言** or **最新近发言**进行排行排行。
- `#老资历` / `#小资历`：按**进群时间**最早、最晚进行排行。
- `#加群大王`：取当前群所在的**互通组**的**并集**，依据群友加入这些**互通组**中的群的数量为当前群的群员做排名。
- `#最老QQ`&`#最短QQ`&`#最小QQ`：按QQ号码升序排行。
- `#最新QQ`&`#最长QQ`&`#最年轻QQ`：按QQ号码降序排行。
- **【补充】：**以上排行类指令均支持@，也可@多人，此时被@的群友会上提到排行榜开头，以方便看到其排名。如无@则默认将触发者上提到开头。

# 查询与头像

- `#查信息` / `#查询信息`：查询自己的注册时间等基本信息。可@人使用。
- `#查看头像` / `#头像时间` / `#头像时长`：查看**当前头像**使用时长。可@人使用。
- `#历史头像 @某人`：将指定群友的全部历史头像打包发出。

# 记录与备注管理

- `#更新群员信息`：主动拉取并更新当前群**全部成员**的昵称、群名片、头衔、权限、头像等信息。
- `#静默更新信息`：同上，但不会有消息反馈。如果是napcat，则会贴表情反馈状态。
- `#删除记录1,2 @某人`：删除指定对象的第 1、2 条历史身份记录；多个编号用逗号分隔。
- `#添加备注 文本 @某人` / `#设置备注 文本 @某人`：给指定群友添加备注。
- `#删除备注1 @某人`：删除指定编号的备注。

# 插件管理

- `#kh帮助`：查看插件帮助文档。
- `#kh统计`：查看kh-plugin的硬盘占用情况。
- `#kh版本`：查看 kh-plugin 的版本信息与更新日志。
- `#kh更新` / `#kh强制更新`：更新 kh-plugin。

# Tips

- 首次使用排行榜前，建议先在对应群发送 `#更新群员信息`以拉取全员信息，否则排行榜不完整。
- **【互通组的概念】：**我们知道，对于同一组织体系下的多个群，其群员往往会有一定重复。比如**鸡哥**和**牢大**，同时加入了 NBA官方**1群** 和 NBA官方**2群** ，意味着在这些群里，他们二人都是对对方可见的。当**鸡哥**在 **1群** 看到了**牢大**陌生有熟悉的面孔，对他使用了`#KH`！由于**鸡哥**可能此前在 **1群** 和 **2群** 都见过**牢大**，那么除了提供**牢大**在当前的**1群**的历史记录以外，我们又提供了**牢大**在**2群**的历史记录，则更有助于**鸡哥**回忆起曾与**牢大**的点点滴滴。由此，对于特定的一些群配置**互通组**，或许能够提供更好的查询体验。
